# Music Quest V2 · Studio Edition（界面版本 2.1.0）

本轮针对用户提供的步骤按钮与导航截图，重做 iPad 优先的乐理学习界面。保留先动画教学、再探索、练习、复习、考评，以及全部课程、微软自然语音和既有学习数据。

## 视觉与操作

- 深海蓝工作台、冰蓝主操作、靛紫音乐轨道、统一 SVG 线条图标。字号、间距、卡片、选项、媒体控制和反馈使用同一套设计变量。
- 1180px 起为完整左侧栏；900–1179px 为紧凑侧栏；899px 及以下为五项底部导航。底部预留安全区，主要导航与语言按钮至少44px，常用操作46–64px。
- 主导航固定为学习大厅、动画课堂、冒险地图、温故知新、知识闯关；课程任务、学习报告和返回童童/小提琴空间集中到右上设置菜单。入口均保留。
- 中法显示、讲解语速进入统一偏好菜单，默认折叠。支持点击外部和Escape关闭，Escape返回菜单焦点。切语言只切文字显示，旋转只改布局，不重建当前题目或抹掉已选答案。
- 大厅由教学主卡、真实每日XP/连学/等级/影片进度、收藏徽章、继续练习分区组成。主卡有课程预览、Mino、缓慢轨道与音符动画；悬停/按下有小幅反馈。减少动态效果设置会关闭装饰动画。
- 教学影片、分阶段进度、旁白、互动操作、答题选项和正确/错误反馈一并更新。步骤样式只作用于直接子项，禁止对子层双语span重复绘制边框；修复截图中的多重圆圈和激活文字低对比。
- 移除模块的外部Google字体请求，使用本机Avenir Next/系统中文字体；未新增运行时库、追踪或外部素材请求。

## 实现范围

更改4项：index.html、css/quest.css（仅直接子项选择器修正）、js/main.js（布局设置/路由状态）、js/ui/rewards.js（教学大厅呈现）；新增css/studio.css。未改题库、347题答案/ID、存储schema/键、奖励计算、音频/视频文件、后端、认证、配置或数据库迁移。

相比本轮开始的构建快照，349个非模块资产和206个原模块资产逐字节保持；新增1个样式文件、4个模块资产改变，无删除。备份private/music-quest-ui-before-20261019，审计audit/music-quest-studio-*。本地开发只在隔离浏览器生成练习数据，不写生产学习记录。
